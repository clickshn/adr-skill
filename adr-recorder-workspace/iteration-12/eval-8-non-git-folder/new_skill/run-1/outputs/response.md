어떤 결정을 ADR로 기록할까요?

자동으로 수집된 최근 변경 컨텍스트가 비어 있어서 기록할 결정을 특정할 수 없습니다.

- 의존성 파일 diff: 비어 있음 — 이 디렉터리는 git 저장소가 아니거나 아직 커밋이 없습니다. (`git diff HEAD` 실패 → "(HEAD 없음: 아직 커밋이 없거나 git 저장소가 아님)")
- 최근 커밋: 없음 — `git log` 실패 → "(커밋 기록 없음)"

대화에서도 명시적으로 언급된 결정이 없어 추측으로 저장소를 뒤지지 않고 여쭤봅니다. 아래 중 해당하는 내용을 알려주시면 바로 ADR을 작성하겠습니다.

- 어떤 결정인가요? (예: 새 라이브러리 도입, DB·통신 방식 변경, 외부 API/서비스 선택 등)
- 왜 그 선택을 했나요? (배경/제약)
- 검토했다가 기각한 대안이 있다면 그 이유는 무엇인가요?

참고로 docs/adr/ 에 기존 ADR이 없으면 ADR-001부터 시작합니다.
