어떤 결정을 ADR로 기록할까요?

의존성 파일 diff(`git diff HEAD -- '*.txt' '*.json' '*.toml' '*.lock'`)가 비어 있고, 이번 대화에서 명시적으로 언급된 결정도 없어서 무엇을 기록해야 할지 특정할 수 없습니다. 추측으로 채우지 않기 위해 저장소 탐색은 하지 않고 멈췄습니다.

아래 중 하나를 알려주시면 바로 ADR을 작성하겠습니다.

- 기록하려는 결정 내용 (예: "이벤트 버스를 RabbitMQ에서 Kafka로 전환하기로 했다")
- 이미 적어둔 결정 로그 위치 (예: `docs/decisions.md`의 특정 항목) — 이관해 드립니다
- 특정 커밋/PR을 근거로 삼고 싶다면 그 대상

참고로 최근 커밋 목록은 아래와 같습니다. 이 중 하나가 기록 대상이라면 지목해 주세요.

```
bca263c fix: 푸시 알림 재시도 백오프 계산 오류
54ba969 test: 이메일 템플릿 스냅샷 테스트 추가
62d9887 feat: 이벤트 버스 RabbitMQ -> Kafka 전환
ceebff3 chore: notification-service 초기 구성
```
