ADR 파일을 만들기 전에 번호 하나만 확인하고 싶어요.

`docs/adr/`를 셸로 직접 확인해 보니 `.gitkeep`만 있고 ADR 파일이 하나도 없습니다. 그런데 이 디렉터리는 이번에 새로 만든 게 아니라 초기 커밋(`f3400b1 chore: partner-gateway 초기 구성, docs/adr 디렉터리 추가`)부터 있던 거라서, 예전 ADR이 다른 곳(위키, 다른 저장소, 다른 브랜치 등)에 있을 수도 있습니다. 그래서 번호를 제가 임의로 정하지 않았습니다.

**이번 ADR 번호를 몇 번으로 할까요?** 이 저장소의 첫 ADR이면 `ADR-001`로 하겠습니다.

번호만 알려주시면 바로 파일로 쓸게요. 들어갈 내용은 정리해 뒀습니다.

- **결정:** API 인증 방식을 express-session 쿠키 세션에서 JWT(`jsonwebtoken ^9.0.2`)로 전환 (`package.json`에서 `express-session ^1.18.0`는 제거)
- **배경:** 파트너사 서버가 붙기 시작하면서 서버 간 호출에 쿠키 기반 세션을 쓰기 번거로워짐
- **기각한 대안:** 세션 방식은 유지하고 파트너용 API 키를 따로 발급하는 방안. 키 회전 관리를 별도로 만들어야 해서 제외
- **Status:** Proposed / **Decision Source:** Human
