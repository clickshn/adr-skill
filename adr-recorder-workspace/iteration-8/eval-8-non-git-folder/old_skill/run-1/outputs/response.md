어떤 결정을 ADR로 기록할까요?

이 폴더에서 참고할 변경 내역이 없었습니다. 의존성 diff는 "(HEAD 없음: 아직 커밋이 없거나 git 저장소가 아님)", 커밋 기록은 "(커밋 기록 없음)"으로 나왔습니다. 대화에서도 특정 결정이 언급되지 않아 ADR을 만들지 않았습니다.

기록할 결정을 알려주세요. 예를 들면 "로깅 라이브러리로 structlog를 쓰기로 했다", "서비스 간 통신을 REST에서 gRPC로 바꾸기로 했다" 같은 식입니다. 검토했다가 기각한 대안과 그 이유도 같이 알려주시면 Alternatives 섹션에 넣겠습니다.
