어떤 결정을 ADR로 기록할까요?

현재 의존성 파일(`*.txt`, `*.json`, `*.toml`, `*.lock`)에 변경 사항이 없고, 대화에서도 기록할 결정이 언급되지 않아 아직 ADR 파일을 만들지 않았습니다.

참고로 최근 커밋 중 `66fc268 feat: 이벤트 버스 RabbitMQ -> Kafka 전환`이 ADR 대상이 될 만한 아키텍처 변경으로 보입니다. 이 결정을 기록할지, 아니면 다른 결정을 기록할지 알려주세요. 가능하면 아래 내용도 함께 알려주시면 좋습니다.

- 결정 내용과 배경 (어떤 문제 때문에 바꿨는지)
- 검토했다가 기각한 대안과 그 이유
