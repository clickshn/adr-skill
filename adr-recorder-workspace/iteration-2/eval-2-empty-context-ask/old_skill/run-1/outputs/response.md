어떤 결정을 ADR로 기록할까요?

현재 의존성 파일(`*.txt`, `*.json`, `*.toml`, `*.lock`)에 커밋되지 않은 변경이 없고, 대화에서도 기록할 결정이 언급되지 않아 ADR 대상을 특정할 수 없습니다.

참고로 최근 커밋 중 `a4afacd feat: 이벤트 버스 RabbitMQ -> Kafka 전환`이 아키텍처 결정으로 보이는데, 이 건을 기록할지 아니면 다른 결정을 기록할지 알려주세요. 결정 내용과 함께 배경, 검토했던 대안, 수치 근거(벤치마크·비용 등)도 알려주시면 더 정확하게 작성할 수 있습니다.
