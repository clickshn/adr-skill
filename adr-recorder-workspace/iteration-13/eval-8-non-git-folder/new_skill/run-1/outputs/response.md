어떤 결정을 ADR로 기록할까요?

현재 자동으로 주입된 컨텍스트가 비어 있어서 기록할 결정을 특정할 수 없습니다.

- 의존성 파일 diff: (HEAD 없음: 아직 커밋이 없거나 git 저장소가 아님)
- 최근 커밋: (커밋 기록 없음)

이 폴더는 git 저장소가 아니라서 변경 이력에서 결정을 추출할 수 없고, 대화에서도 아직 구체적인 결정이 언급되지 않았습니다. 기록하고 싶은 결정을 알려주시면 바로 ADR로 작성하겠습니다. 예를 들면 이런 것들입니다.

- 새로 추가한 라이브러리/의존성과 그걸 고른 이유
- DB, 통신 방식, 메시징 등 아키텍처 변경
- 외부 API·서비스 선택 또는 교체

결정 내용과 함께 기각한 대안이 있었다면 그 근거도 같이 알려주시면 더 정확하게 정리할 수 있습니다.
